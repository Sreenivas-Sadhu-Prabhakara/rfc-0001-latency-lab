## Community post

We are turning the RFC series into small, useful learning tools. This edition explores RFC 1, a legacy Host Software proposal, through Latency Lab. Compare immediate local text feedback with a simulated remote echo, and calculate a deliberately sequential round-trip budget. This is an illustrative comparison. Code points are used as a proxy for keystrokes; edits, composition, pipelining and server work are excluded. It is not a measured performance improvement or a modern transport model.

Try it: https://sreenivas-sadhu-prabhakara.github.io/rfc-0001-latency-lab/

## Teaching exercise

Use 1,000 ms and type a sentence. Then set 0 ms. Which display changes? Compare sending a whole line once with the deliberately serial per-character budget.
