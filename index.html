Read RFC 1 ↗Status & errata ↗

RFC 1 discusses keeping simple console interactions local instead of asking a distant host to handle every keystroke. It uses editing a short line as an example.

This lab gives teachers and interface designers a tangible way to discuss responsiveness. Immediate feedback helps a person see their input even when the network is slow.

This is an illustrative comparison. Code points are used as a proxy for keystrokes; edits, composition, pipelining and server work are excluded. It is not a measured performance improvement or a modern transport model. Official index status: UNKNOWN (Legacy stream). This project is independent of the RFC Editor and IETF.

Try it with someone

A two-minute experiment

Use 1,000 ms and type a sentence. Then set 0 ms. Which display changes? Compare sending a whole line once with the deliberately serial per-character budget.
